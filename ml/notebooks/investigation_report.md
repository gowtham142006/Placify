## 6. Target Randomness Investigation

### Evidence Summary

The Mutual Information comparison between real and shuffled targets (Section 3) provides the definitive test:

| Feature | MI (Real Target) | MI (Shuffled Target) |
|---------|-----------------|---------------------|
| gender | 0.0091 | 0.0091 |
| college_tier | 0.0060 | 0.0031 |
| branch | 0.0042 | 0.0043 |
| cgpa | **0.0002** | **0.0018** |

**The shuffled target produces MI scores of the same magnitude as the real target.** In some cases (cgpa, branch), the shuffled target actually has *higher* MI than the real target. This is the statistical fingerprint of a target variable that carries no meaningful relationship to the features.

### Expected Behavior in a Real Dataset
In a real-world placement dataset:
- CGPA would have MI >> 0.05 (typically 0.1–0.3)
- Skill scores would show strong differentiation (e.g., 30% vs 85% placement rates)
- Shuffled targets would produce MI scores orders of magnitude lower than real targets
- Models would achieve ROC-AUC > 0.80

### Result
**The real target is statistically indistinguishable from a randomly generated target.**

## 7. Root Cause

> [!CAUTION]
> **ROOT CAUSE: The dataset is a synthetic/generated dataset where `placement_status` was assigned with little-to-no dependence on student features.**

### Evidence Chain

1. **No data generation code exists in the repository** — The 100K-row CSV was imported from an external source.

2. **All features are generated independently** — Feature interaction analysis shows perfectly uniform sample sizes across all tercile combinations (~11K each), which is the hallmark of independent random sampling.

3. **Feature distributions are identical for Placed vs Not Placed** — Mean differences are less than 1-2% of the feature range across ALL features.

4. **Mutual Information is effectively zero** — Max MI = 0.009, and MI scores for the real target are indistinguishable from a shuffled (random) target.

5. **All models perform at near-random levels** — ROC-AUC 0.55-0.58 (random = 0.50).

6. **Group-based placement rates are flat** — CGPA <6 (53.3%) vs CGPA >8 (55.1%) — a 1.7% difference is meaningless.

7. **The pipeline is correct** — No data leakage, correct preprocessing, proper train/test split.

The problem is **not** with the ML pipeline, feature engineering, or model selection. **The problem is that the dataset itself contains no predictive signal.** The target variable `placement_status` was generated with at most a very slight probabilistic bias from the features — essentially randomly.
